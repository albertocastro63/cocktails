# Implementation Plan: Recipe Sort Order on All Recipes Page

**Branch**: `013-recipe-sort-order` | **Date**: 2026-05-21 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/013-recipe-sort-order/spec.md`

## Summary

Add an adjacent toggle button pair (A→Z | Z→A) to the all-recipes page that client-side-sorts the already-loaded recipe list by name. A new `SortButtonGroup` component encapsulates the button group with full WCAG 2.1 AA accessibility (`aria-pressed`, `role="group"`, keyboard operability). Sort state is ephemeral: the page loads in server order with no direction pre-selected; navigating away resets it.
