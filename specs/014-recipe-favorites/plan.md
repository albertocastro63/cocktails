# Implementation Plan: Recipe Favorites

**Branch**: `014-recipe-favorites` | **Date**: 2026-05-22 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/014-recipe-favorites/spec.md`

## Summary

Allow logged-in users to mark recipes created by others as favorites via a heart icon on the recipe detail page. Favorites are persisted server-side, appear on the "My Recipes" page as a unified list with heart badges, and meet WCAG 2.1 AA accessibility requirements.

**Approach**: New `cocktails-favorites` DynamoDB table (composite key `user_id + recipe_id`) + `FavoriteStore` interface + 4 REST endpoints + `FavoriteButton` frontend component + `MyRecipes` / `RecipeDetail` integration.

## Technical Context

**Language/Version**: Go 1.22 (backend), Vanilla JS ES modules (frontend)
**Primary Dependencies**: `aws-sdk-go-v2` (DynamoDB), `net/http` stdlib mux, Tailwind CSS v3, Vite 8, Vitest 4 + jsdom
**Storage**: DynamoDB (prod) + SQLite (local dev) — new `cocktails-favorites` table in both
**Testing**: Go `testing` package + `httptest` (backend); Vitest 4 + jsdom + `vi.mock` (frontend)
**Target Platform**: AWS Lambda (arm64, Go `provided.al2023`) + CloudFront/S3 SPA
**Project Type**: Web application (Go backend + vanilla JS frontend)
**Performance Goals**: Favorite toggle ≤ 500 ms write p95; page load unaffected (parallel fetches)
**Constraints**: No new npm dependencies; no new Go modules; single new DynamoDB table
